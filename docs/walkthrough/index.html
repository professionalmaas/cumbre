Cumbre, clicked through end to end

Cumbre grades a song the way an A&R listener would, without knowing who made it. Upload a track, get a 0 to 100 summit score for music and lyrics, and the top three fixes. The score comes from an owned feature pipeline; no Spotify API, no rented model weights.

03 · Upload

Pick the route, confirm the rights

Drop an MP3 or WAV, choose the genre you are climbing in, the depth of the read, and whose ears to use: listener, producer or A&R. The rights warranty is required. Grading is free; payment unlocks the full report.

04 · Analyzing

The engine runs; the page updates itself

Listening to the mix, reading the lyrics, charting the melody, scoring the route. Locally the Python worker runs inline; in production it is a Fargate task behind Step Functions with a task token. The page polls the job row and flips on its own.

05 · Teaser (production)

The score is free, the route is paid

In production every run produces a teaser with the summit score and verdict, and the full report sits behind one credit or a season pass; new users get one credit on first sign-in. In the local build the entitlement is auto-granted, so the report opens in full with no pay step.

06 · Full report

Your own track, scored

The page flips from Analyzing to the full report on its own, about four seconds after upload once the engine is warm. The highlight plays your own upload from memory during the session; the audio file itself is deleted after analysis, and only the feature vector and scores are kept.

07 · Share

A public summit card

Each result gets a share token. The public page shows the score and verdict only, with an Open Graph image generated per report, and invites the reader to grade their own song.

Run it yourself

Needs Docker Desktop, Node 20+ and Python 3.10+. One command installs the web packages and the analyzer, writes the local env file, starts Postgres, applies the schema and opens the app.

git clone https://github.com/professionalmaas/cumbre
cd cumbre
node scripts/local.mjs
# then open http://localhost:3000 and choose "Continue as dev user"

Leave ANTHROPIC_API_KEY empty and the written notes come from a deterministic heuristic; set it and a language model writes them. DEV_MODE is forced off under NODE_ENV=production or on ECS, so a deploy cannot skip auth or billing.
